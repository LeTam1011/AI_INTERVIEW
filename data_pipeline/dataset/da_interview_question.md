1. ### Mention the differences between Data Mining and Data Profiling?

    Data Profiling focuses on analyzing individual datasets for quality, patterns, and statistics. Data Mining focuses on discovering hidden patterns and relationships across large datasets to predict future trends.

2. ### Define the term 'Data Wrangling in Data Analytics.

    Data Wrangling (or Data Munging) is the process of cleaning, transforming, and mapping raw data into a more usable format for analysis.

3. ### What are the various steps involved in any analytics project?

    Typical steps include: 1. Understanding the problem; 2. Data collection; 3. Data cleaning; 4. Exploratory Data Analysis (EDA); 5. Statistical modeling/Data Mining; 6. Communication of results.

4. ### What are the common problems that data analysts encounter during analysis?

    Common problems include missing data, inconsistent data formats, outliers, duplicate records, and data from non-integrated sources.

5. ### Which are the technical tools that you have used for analysis and presentation purposes?

    [Personalized] Examples include Excel, SQL, Python (Pandas/Matplotlib), R, Tableau, Power BI, and Google Data Studio.

6. ### What are the best methods for data cleaning?

    Methods include removing duplicates, handling missing values (imputation or deletion), standardizing data formats, and detecting/removing outliers.

7. ### What is the significance of Exploratory Data Analysis (EDA)?

    EDA helps understand the data's underlying structure, detect outliers, check assumptions, and identify initial patterns or relationships before formal modeling.

8. ### Explain descriptive, predictive, and prescriptive analytics.

    Descriptive: Tells you what happened in the past. Predictive: Tells you what might happen in the future. Prescriptive: Suggests actions to take based on the predictions.

9. ### What are the different types of sampling techniques used by data analysts?

    Techniques include Simple Random Sampling, Stratified Sampling, Cluster Sampling, and Systematic Sampling.

10. ### Describe univariate, bivariate, and multivariate analysis.

    Univariate: Analyzing one variable. Bivariate: Analyzing the relationship between two variables. Multivariate: Analyzing the relationship between three or more variables.

11. ### What are your strengths and weaknesses as a data analyst?

    [Personalized] Strengths: Attention to detail, logical thinking, tool proficiency. Weaknesses: Over-analyzing, or learning to better present data to non-technical audiences.

12. ### What are the ethical considerations of data analysis?

    Key considerations include data privacy (protecting personal info), ensuring data security, avoiding algorithmic bias, maintaining transparency in methods, and obtaining proper informed consent.

13. ### What are some common data visualization tools you have used?

    [Personalized] Common tools include Tableau, Power BI, QlikView, and Python libraries like Matplotlib, Seaborn, and Plotly for more customized charts.

14. ### How can you handle missing values in a dataset?

    Techniques include: 1. Deletion (listwise or pairwise); 2. Imputation (filling with mean, median, or mode); 3. Prediction models to estimate values; 4. Using algorithms that support missing values.

15. ### Explain the term Normal Distribution.

    A probability distribution that is symmetric about the mean, showing that data near the mean are more frequent in occurrence than data far from the mean (forming a bell curve).

16. ### What is Time Series analysis?

    A statistical technique that deals with time series data, or trend analysis. It is used to extract meaningful statistics and characteristics to forecast future values based on previously observed values.

17. ### How is Overfitting different from Underfitting?

    Overfitting occurs when a model is too complex and learns noise in the training data. Underfitting occurs when a model is too simple to capture the underlying trend of the data.

18. ### How do you treat outliers in a dataset?

    Methods include: 1. Trimming/Removal; 2. Capping (Winsorization); 3. Data transformation (e.g., log transform); 4. Using robust statistical methods that are less sensitive to outliers.

19. ### What are the different types of Hypothesis testing?

    Common types include Z-test, T-test (paired/unpaired), ANOVA, Chi-square test, and F-test, depending on the data distribution and sample size.

20. ### Explain the Type I and Type II errors in Statistics?

    Type I error (False Positive) occurs when we reject a true null hypothesis. Type II error (False Negative) occurs when we fail to reject a false null hypothesis.

21. ### How would you handle missing data in a dataset?

22. ### Explain the concept of outlier detection and how you would identify outliers in a dataset.

    Outlier detection finds data points that differ significantly from others. Identification methods include Z-score, IQR (Interquartile Range) method, and visual tools like Box plots and Scatter plots.

23. ### In Microsoft Excel, a numeric value can be treated as a text value if it precedes with what?

24. ### What is the difference between COUNT, COUNTA, COUNTBLANK, and COUNTIF in Excel?

    COUNT: counts cells with numbers. COUNTA: counts non-empty cells. COUNTBLANK: counts empty cells. COUNTIF: counts cells that meet a specific criterion.

29. ### Explain how VLOOKUP works in Excel?

    VLOOKUP (Vertical Lookup) searches for a value in the first column of a table array and returns a value in the same row from a specified column number.

31. ### How is joining different from blending in Tableau?

    Joining combines data from the same source at the row level. Blending combines data from different sources (databases/files) by aggregating data first and then linking on a common field.

32. ### What do you understand by LOD in Tableau?

33. ### Can you discuss the process of feature selection and its importance in data analysis?

    Feature selection involves choosing a subset of relevant variables for use in model construction. It is important to reduce overfitting, improve model accuracy, and decrease computational time.

34. ### What are the different connection types in Tableau Software?
